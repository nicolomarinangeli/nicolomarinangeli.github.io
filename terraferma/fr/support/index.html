Écrire

Pour tout problème, question ou idée : nicolom.dev.supporto@gmail.com

Je réponds en quelques jours. Pour signaler un bug, il est utile de connaître l'appareil, la version d'iOS ou de macOS, la carte et le mode, ce que vous faisiez et ce qui s'est passé à la place.

Avant d'écrire

Comment jouer

Dans le menu, « Comment jouer » explique l'expansion, les attaques, les navires, les chemins de fer, les bombes et les alliances, avec des conseils pour les premières parties.

« Amis » ou « Dans le monde » ne trouve personne

Les parties avec d'autres joueurs utilisent Game Center : connectez-vous dans les réglages de l'appareil, à la rubrique Game Center, et vérifiez la connexion internet. Pour jouer entre amis, l'un crée le salon et les autres le rejoignent avec son code. Tout le monde doit avoir la dernière version de Terraferma.
